## Project Description
A satirical, interactive web application that uses live machine learning (MediaPipe) to track and scan the user's hand. Instead of genuine fortune-telling, the app generates brutal, localized Manglish roasts about the user's lifestyle, complete with unhinged UI mechanics designed to mess with them.

## The Problem (that doesn't exist)
People have way too much confidence and need to be humbled by their own webcams. Existing fortune tellers are too nice and don't roast your KTU SGPA, your 2 AM overthinking sessions, or your non-existent love life.

## The Solution (that nobody asked for)
An overly dramatic, fake ML palm scanner that traps the user. We built a system that fakes a brain-hacking terminal, edges the user by pausing at a 99% loading screen, and features a "Cancel" button that physically dodges the mouse pointer so they can't escape the emotional damage.
